# FWebServer
FWebServer is a simple opensource web-server written fully on rust 

![](https://files.catbox.moe/2f32gx.png)

To build the server, open a terminal and type this in:
```
git clone https://github.com/Foxy3049/FWebServer.git
cd FWebServer
cargo build --release
```

To run the server:
```
cd target/release
./fwebserver [Path to a directory]
```
